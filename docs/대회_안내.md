## 해커톤 주제

**AI를 통해 인간다움을 더욱 잘 드러낼 수 있는 서비스 개발**

1. 문제 정의 — 사람에게 진짜 필요한 문제인가
2. AI 활용 — AI는 목적이 아닌 문제 해결의 도구
3. 개발 유형 — 웹·모바일 앱 등 형태 제한 없음

## 예선 제출물 (4가지 필수)

1. 발표 자료 — 문제 정의·사용자·핵심 기능·AI 활용 방식·기대 효과
2. 코드 저장소(GitHub) — README·실행 방법·주요 코드·커밋 내역·**AI 지침 파일**
3. 배포/데모 — 실제 작동 링크 또는 데모 영상·스크린샷·테스트 계정 안내
4. AI 활용 증빙 — 모델·API 사용 위치·프롬프트/설정·테스트·검증 산출물

작성 팁: 기능 중심(주제를 정확히 표현하는 기능 위주) · 근거 중심(AI 사용이
필수적인 근거) · 실현 가능(사용자가 실제로 쓸 수 있는 형태)

- AI가 적격성 자동 판정 + 점수 초안 작성 → 심사위원 3인(Upstage 앰버서더,
  APPTIVE 1인, Untoc 1인)이 리포트 참조 후 최종 채점
- **팀당 독립 3회 실행 후 평균 산출.** 편차가 큰 팀은 심사위원이 정밀 재검토
  → 제출물 표현이 애매하면 실행마다 판정이 달라질 위험이 있으므로, README와
  발표 자료에서 핵심 메시지를 일관되게 반복할 것
- README·코드 주석 등에 심사 지시를 넣는 **프롬프트 인젝션은 적발 시 실격**
